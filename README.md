# پنل مستقل گلخانه‌دار پیوندگستر پارسان

این مخزن فقط شامل رابط کاربری پنل گلخانه‌دار است و چرخه انتشار مستقلی از پنل کارشناس و پنل مدیریت دارد.

## انتشار

- انتشار خودکار با GitHub Actions در هر تغییر شاخه `main` انجام می‌شود.
- پس از فعال‌سازی GitHub Pages، نشانی موقت پروژه:
  `https://shamshiri13461353.github.io/greenhouse-grower-portal/`
- دامنه اختصاصی `grower.peyvandgostar.com` پس از تنظیم DNS و ثبت دامنه در تنظیمات Pages فعال خواهد شد.

## زیرساخت و امنیت

- داده‌ها و احراز هویت از پروژه مشترک Supabase دریافت می‌شوند.
- کلاینت از Supabase publishable key استفاده می‌کند؛ کلیدهای service_role و اسرار سرور نباید در این مخزن قرار گیرند.
- سیاست‌های RLS و Storage در Supabase مسئول کنترل دسترسی داده‌ها هستند.
- کتابخانه مرورگری Supabase از CDN بارگیری می‌شود؛ برای ورود و کار با پرونده‌ها اتصال اینترنت لازم است.

## محدوده مخزن

این مخزن شامل پنل گلخانه‌دار است. کد پنل کارشناس، پنل مدیریت، مهاجرت‌های پایگاه داده و فایل‌های نصب‌کننده در این مخزن کپی نمی‌شوند.


آخرین بررسی انتشار: فعال‌سازی GitHub Pages از طریق تنظیمات مخزن انجام شده است.
